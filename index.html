About this release

This release adds a settings panel: language, search engine, calendar type, 24-hour clock, seconds, shortcuts visibility, wallpaper blur, and optional Google account sign-in to personalize your local profile experience.

win11-newtab.zip ZIP

How to install

  1. Download the ZIP file and extract it.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder.

This extension is not listed on the Chrome Web Store yet.
